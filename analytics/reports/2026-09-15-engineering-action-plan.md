## 1. תקציר ממצאים קריטיים (Executive Diagnosis)

שלוש נקודות הכשל אינן שלוש בעיות נפרדות. הן **שרשרת סיבתית אחת**: באג עוצר סקריפט,
ביצועים מאריכים את חלון הפגיעות, וארכיטקטורת נחיתה מכוונת את כל התקציב בדיוק לתוכו.

### 🔴 כשל #1 — שגיאת תחביר ב-JavaScript שמשביתה רכיבי המרה בשבעה עמודים

**הראיה:** השגיאה `unexpected token: identifier` חוזרת בשבעה עמודים, ובראשם **דף הבית
ועמוד "צור קשר"**. בנוסף `Script error.` ×5 בדף הבית.

שגיאת תחביר **עוצרת את הרצת הסקריפט כולו** מנקודת הכשל. כל מאזין אירועים שנרשם באותו
סקריפט לא נקשר לעולם. זה מסביר, בגורם שורש אחד, את שלושת הכשלים הנפרדים לכאורה:

| תופעה | ראיות | מוסבר על ידי כשל #1? |
|---|---|---|
| כפתורי "חיוג מהיר"/"וואטסאפ" נכשלים לסירוגין | 5+6 מקרים מתועדים | ✅ |
| רכיב בורר/מחשבון לא מגיב | 5 סשנים, 4 עמודים | ✅ |
| מקור ה-Rage Click היחיד בכל התקופה | 29/08 07:25 | ✅ |
| טפסים שנזנחו אחרי הקלדה | 3 סשנים | ✅ חלקית |

**הראיה המכריעה לכך שזה באג ולא עומס:** אותם כפתורים בדיוק **עובדים** בהקלטות אחרות
(6 הקלטות השוואה מתועדות). כפתור שעובד לפעמים אינו כפתור שבור — הוא כפתור שהקישור שלו

**מה כן מסכן את ה-SEO — וזה טכני, לא התנהגותי:**

|---|---|

| CLS 0.94 / 0.90 / 0.68 / 0.58 (סף: 0.1) | 🔴 פי 9 מהסף |
| שגיאות JS ב-7 עמודים | 🟠 פוגע בעיבוד וברינדור |

#### 4.2 Information Gain למנועי AI

**נכסים חזקים שכבר קיימים:** תוכן FAQ שהמשתמשים צורכים בפועל (7 ו-4 קליקים בסשן),
טבלאות מחיר, ונתונים הנדסיים. זה בדיוק סוג התוכן ש-AI Overviews ו-Perplexity מצטטים.

**מה חוסם אותם כרגע:**

1. 🔴 **`window.dataLayer = window...` כטקסט גלוי** — LLM שסורק את העמוד קולט קוד
   כתוכן. זה מזהם את הייצוג הסמנטי של העמוד ופוגע באמון.
2. 🟠 **תוכן ה-FAQ ככל הנראה אינו מסומן ב-`FAQPage` schema** — לא ניתן לאמת בלי גישה
   ל-DOM, אך היעדר סימון הוא ברירת המחדל ב-Elementor.
3. 🟠 **טבלאות מחיר** — אם הן מיוצרות כתמונות או כ-`div` מעוצבים במקום `<table>`
   סמנטי, הן בלתי נגישות ל-LLM. לא ניתן לאמת מכאן.
4. 🟠 **שגיאות JS** עלולות לעצור רינדור תוכן שנטען דינמית — תוכן שלא נרנדר לא נסרק.

## 4. הנחיות יישום קונקרטיות

> ⚠️ לא הייתה לי גישה ל-DOM. התאם את הסלקטורים למבנה הקיים.

### 4.1 F-03 · CTA שעובד לפני טעינת ה-JavaScript

**העיקרון:** הכפתור חייב להיות קישור אמיתי ב-HTML. ה-JS רק *משפר* אותו, לעולם לא *מפעיל* אותו.

```html
<!-- ❌ לפני: תלוי לחלוטין ב-JS -->
<div class="btn-call" onclick="initCall()">חיוג מהיר</div>

<!-- ✅ אחרי: עובד גם אם ה-JS נכשל לחלוטין -->
<a href="tel:+9727781231110" class="btn-call" data-track="call">חיוג מהיר</a>
<a href="https://wa.me/9727781231110?text=%D7%A9%D7%9C%D7%95%D7%9D" class="btn-wa"
   rel="noopener" data-track="whatsapp">וואטסאפ</a>
```

```js
// המדידה נרשמת, אבל לעולם לא חוסמת את הניווט
document.addEventListener('click', function (e) {
  var el = e.target.closest('[data-track]');
  if (!el) return;
  try { window.dataLayer && window.dataLayer.push({event: 'cta_' + el.dataset.track}); }
  catch (err) { /* המדידה נכשלה — הקישור ממשיך לעבוד */ }
}, {passive: true});
```

**למה זה מחסל את הבאג:** האזנה אחת ברמת ה-`document` (event delegation) במקום קישור
פר-אלמנט. אין חלון זמן שבו הכפתור "עוד לא מחובר" — ואפילו אם הסקריפט כולו נכשל,
`href` עובד.

**מדד הצלחה:** אפס Dead Clicks על "חיוג מהיר" ו"וואטסאפ" בשבוע העוקב.

הגולש לחץ שוב ושוב על "3,000 – 5,000" ולא קיבל דבר. גם אחרי תיקון הבאג, **חייב להיות

### 4.4 F-07 · קיצור הטופס

17 אירועי הקלדה ללא שליחה = טופס ארוך מדי או כפתור שליחה שלא נראה.

```html

  <p class="reassure">נחזור אליכם תוך שעת עבודה. ללא התחייבות.</p>

```

```css
.lead-form input{min-height:52px; font-size:16px} /* 16px מונע זום אוטומטי ב-iOS */
.lead-form .submit{

  background:#0b5c8a; color:#fff; border:0; border-radius:10px;
```

**שלושה שינויים, כל אחד מבוסס ראיה:**
1. **שני שדות בלבד** — טלפון ושם. אימייל אינו נדרש לחזרה טלפונית.
2. **`font-size:16px`** — מתחת ל-16px, iOS מבצע זום אוטומטי ומזיז את הפריסה. זו סיבה
   מתועדת לזניחת טפסים במובייל, והיא עקבית עם פער המובייל שנמדד.
3. **כפתור `sticky`** — נשאר גלוי כל זמן המילוי.

> **לפני שתקצר — צפה בשלוש ההקלטות של הטפסים שנזנחו.** לא ניתן לדעת מהנתונים באיזה
> שדה בדיוק נטשו. שלוש הקלטות יענו על כך בוודאות תוך חמש דקות.

**מדד הצלחה:** לפחות 8 אירועי `SubmitForm` בשבוע (מול 3 כיום).
