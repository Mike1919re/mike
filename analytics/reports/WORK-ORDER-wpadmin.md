## 0.3 · אימות ההשערה על Perfmatters — 3 דקות

`Settings → Perfmatters → Assets → JavaScript`

רשום את הערכים **לפני** שאתה נוגע:

| הגדרה | ערך נוכחי | משמעות |
|---|---|---|
| Delay JavaScript | ☐ מופעל / ☐ כבוי | |
| Delay Behavior | ☐ All Scripts / ☐ Specific Scripts | "All" = כל ה-CTA מושהים |
| Delay Timeout | ____ שניות | בעמוד שנטען 20.6 שנ' זה חלון ענק |
| Exclusions | העתק את התוכן | |

**מבחן ההכרעה (ללא קונסולה):**

1. פתח **חלון גלישה בסתר** — חובה. משתמש מחובר כ-admin עוקף מטמון ומייצר ממצאי שווא.
2. טען את דף הבית והמתן לסיום מלא.
3. לחץ **לחיצה אחת בלבד** על "חיוג מהיר".

| תוצאה | מסקנה |
|---|---|
| לא קרה כלום, לחיצה שנייה עבדה | ✅ **HYPOTHESIS אושרה** — Delay JS הוא הגורם |
| עבד בלחיצה הראשונה | ❌ **ההשערה הופרכה** — עצור ודווח. הגורם אחר |

4. חזור על אותו מבחן עם `Delay JavaScript` **כבוי זמנית** + ניקוי מטמון.
   אם הכפתור עובד בלחיצה ראשונה — **הוכחת סיבתיות.** החזר את ההגדרה למצבה.

`Elementor → Templates → Theme Builder → Header` (או Footer).

# גל A · F-05 — הסרת הקוד הגלוי

## ⚠️ שער תלויות — קרא לפני שאתה מוחק

**מה עוד תלוי בקוד הזה?** `window.dataLayer` הוא ה-bootstrap של Google Tag Manager.
אם זה העותק **היחיד**, מחיקתו משביתה בשרשרת:

```
dataLayer → GTM → GA4 → ייבוא המרות לגוגל אדס → קהלי רימרקטינג
```

**אימות חובה לפני המחיקה:** ודא שקיים **עותק תקין נוסף** של סניפט GTM —
ב-WPCode (`Header`), ב-Site Kit, או בתבנית הילד.

| ממצא | פעולה |
|---|---|
| קיים עותק תקין נוסף | ✅ המשך למחיקה |
| **זה העותק היחיד** | 🛑 **עצור.** קודם התקן סניפט GTM תקין ב-WPCode, אמת שהוא פועל, ורק אז מחק את הגלוי |

**החוק:** בנה את התחליף **לפני** ההסרה. לא אחריה.

## הביצוע

1. **מחק את הווידג'ט/הטקסט** שאיתרת ב-0.5. אל תערוך — מחק את הרכיב כולו.
2. **עדכן** את העמוד ב-Elementor.
3. **נקה מטמון** בסדר הזה: Perfmatters → `Clear Used CSS` + `Clear Cache` ← מטמון שרת ← CDN.
4. גלוש בסתר: הטקסט נעלם? העמוד לא נשבר ויזואלית?

## למה למחוק ולא להעביר לתגית תקינה

הקוד הזה כבר עבר סינון WordPress — ייתכן שהוא חסר, חתוך או עם מרכאות שהומרו.
**אין לסמוך על הטקסט הזה כמקור.** ההתקנה הנכונה היא סניפט GTM נקי מהמקור הרשמי.

**Rollback:** בטל את המחיקה בהיסטוריית הגרסאות של Elementor.

## מה יקרה למדדים

| מדד | צפוי | מדאיג |
|---|---|---|
| טקסט גלוי בעמוד | נעלם | — |
| Dead Clicks על אותו טקסט | יורד לאפס | — |
| **אירועי GA4 / dataLayer** | **ללא שינוי** | 🔴 **ירידה לאפס = שברת את המדידה. גלגל אחורה מיד** |

**שער:** המתן **24 שעות** ואמת בגוגל אנליטיקס שהאירועים זורמים כרגיל לפני שתמשיך לגל B.
