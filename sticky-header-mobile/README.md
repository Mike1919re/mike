# הדר דביק בתצוגת מובייל — teleco.co.il ומרכזיות טלפון

הדר שנעול לראש המסך במובייל בלבד. בדסקטופ שום דבר לא משתנה.
אותו קוד בדיוק לשני האתרים — אין גרסה נפרדת לכל אתר.

## קודם כול: אולי אתה בכלל לא צריך את הקוד הזה

אם באתר יש **Elementor Pro**, הדרך הנכונה היא המובנית, לא סניפט:

> ערוך את ההדר ב-Theme Builder ← בחר את ה-Container/Section הראשי של ההדר ←
> **Advanced ← Motion Effects ← Sticky: Top** ← ב-**Sticky On** השאר **Mobile** בלבד
> (בטל Desktop ו-Tablet) ← Effects Offset: 0.

זו ההמלצה המקצועית שלי כברירת מחדל: אלמנטור מטפל בעצמו ב-spacer, בתצוגה
המקדימה בתוך העורך ובעדכוני גרסה, ואין קוד שצריך לתחזק.

**השתמש בסניפט שכאן אם:** האתר על Elementor Free, או שה-Sticky המובנה
נשבר (ההדר קופץ, התוכן מזנק כלפי מעלה, או ההדר נעלם בגלילה) — מה שקורה
כשיש אב-קדמון עם `transform` שמבטל `position: fixed`. הסניפט מזהה ומנטרל
בדיוק את המקרה הזה.

## התקנה — מסלול מהיר (סניפט אחד, מומלץ)

קובץ אחד להדבקה: [`sticky-header-mobile.snippet.html`](sticky-header-mobile.snippet.html)
(מכיל גם CSS וגם JS). בצע בכל אחד משני האתרים בנפרד:

### Elementor Pro
1. **Elementor ← Custom Code ← Add New**
2. שם: `Sticky Header Mobile`
3. **Location: `</body> - End`**, Priority: 10
4. הדבק את כל תוכן `sticky-header-mobile.snippet.html`
5. **Publish ← Display Conditions ← Entire Site**

### וורדפרס בלי Elementor Pro (תוסף WPCode / Code Snippets)
1. **Code Snippets ← Add Snippet ← HTML Snippet**
2. הדבק את תוכן הקובץ
3. Location: **Site Wide Footer**, Status: Active

> ⚠️ אל תדביק את הסניפט ב-**Appearance ← Customize ← Additional CSS** —
> זה שדה CSS בלבד, תגיות `<style>`/`<script>` לא יעבדו שם.

## התקנה — מסלול קבצים נפרדים

למי שמעדיף לטעון כקבצים דרך התבנית (child theme):

| קובץ | לאן |
|---|---|
| `sticky-header-mobile.css` | `wp_enqueue_style` |
| `sticky-header-mobile.js` | `wp_enqueue_script`, בפוטר (`$in_footer = true`) |

ה-CSS **לא עובד לבד** — הוא מסתמך על המחלקות ומשתני ה-CSS שה-JS מוסיף.
אחרי שינוי באחד מהם הרץ `./scripts/build-sticky-snippet.sh` כדי לבנות מחדש
את קובץ הסניפט, כדי ששתי הגרסאות לא ייפרדו.

## בדיקה אחרי ההתקנה

1. פתח את האתר בנייד (או DevTools ← Device Toolbar ← iPhone).
2. גלול למטה — ההדר נשאר למעלה, התוכן **לא** קופץ בטעינה.
3. פתח את תפריט ההמבורגר — כל הפריטים נגישים, גם במסך נמוך/לרוחב.
4. הרחב לדסקטופ — ההדר חוזר להתנהגות המקורית ונגלל החוצה.
5. לחץ על קישור עוגן בתוך הדף — היעד לא מוסתר מתחת להדר.

## התאמות

הוסף `<script>` עם `window.SHM_CONFIG` **לפני** הסניפט, או ערוך את `CONFIG` בתוכו:

```html
<script>
window.SHM_CONFIG = {
  maxWidth: 767,      // מעל זה — התנהגות רגילה. 1024 = כולל טאבלט.
  selector: '',       // סלקטור מפורש, אם הזיהוי האוטומטי טעה
  shadow: true,       // צל אחרי תחילת גלילה
  debug: false        // true = הדפסת אבחון לקונסול
};
</script>
```

שליטה בעיצוב דרך CSS:

```css
:root {
  --shm-bg: #0b1f3a;                     /* רק אם ההדר שקוף (ראה למטה) */
  --shm-shadow: 0 2px 10px rgba(0,0,0,.12);
  --shm-z: 9990;                          /* אם משהו באתר מכסה את ההדר */
}
```

## איך זה עובד

* **זיהוי אוטומטי של ההדר** לפי רשימת סלקטורים מדורגת — מהעטיפה החיצונית של
  אלמנטור (`.elementor-location-header`) ועד `header#masthead` של תבנית רגילה.
  לא נמצא הדר? מודפסת אזהרה לקונסול עם ההוראה להגדיר `selector`.
* **spacer במקום padding ל-body** — נשתל אלמנט בגובה ההדר במקומו המקורי
  במסמך, כך שאין קפיצה של התוכן ואין התנגשות עם ה-padding של התבנית.
* **גובה נמדד, לא מנוחש** — `ResizeObserver` + טעינת פונטים + סיבוב מסך.
  הלוגו נטען מאוחר? המרווח מתעדכן.
* **סרגל הניהול של וורדפרס** — נספר רק כשהוא באמת `fixed` (מתחת ל-600px
  וורדפרס הופך אותו ל-`absolute` והוא נגלל החוצה, ואז אין היסט).
* **אב-קדמון ששובר `fixed`** — `transform`/`filter`/`perspective`/`contain`
  הופכים אב-קדמון ל-containing block, ואז `position: fixed` מתנהג כמו
  `absolute` וההדר נגלל החוצה. מנוטרל על שרשרת ההורים של ההדר בלבד,
  ורק בזמן שהדביקות פעילה.
* **תפריט פתוח** — ההדר עצמו הופך לאזור גלילה, כדי שתפריט ארוך לא ייחתך
  מתחת לקצה המסך. ה-spacer לא גדל בזמן שהתפריט פתוח, כדי שהדף לא יקפוץ.
* **הרקע של האתר נשאר** — רקע נוסף מוחל רק אם ההדר שקוף לגמרי (overlay מעל
  תמונת פתיחה), כי אז התוכן שנגלל מתחתיו הופך אותו לבלתי קריא.
* **לא רץ בעורך אלמנטור** — שם ההדר חייב להישאר בזרימה הרגילה.

## מה נבדק

נבדק ב-Chromium בשלוש תצורות: הדר אלמנטור עם אב-קדמון בעל `transform`
ועם סרגל ניהול; תבנית וורדפרס רגילה (`header#masthead`) בלי אלמנטור;
והדר שקוף מעל תמונת פתיחה. נבדקו: `position: fixed` בפועל, התאמת גובה
ה-spacer, אפס קפיצת תוכן, נעילה לראש אחרי גלילה, פתיחה וסגירה של תפריט
ההמבורגר, שמירת הרקע והלוגו המקוריים, וכיבוי מלא בדסקטופ כולל מעבר
דינמי בין הרזולוציות.
